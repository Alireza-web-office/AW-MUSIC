# AW MUSIC | ALIREZA WEB

نسخه اولیه اندروید با Kotlin برای فهرست و پخش موسیقی‌های دستگاه.

## ساخت APK
1. ZIP را استخراج کن.
2. محتویات پوشه AW-MUSIC-project را در ریشه مخزن GitHub بارگذاری کن (خود ZIP را نه).
3. Commit changes را بزن.
4. در Actions اجرای Build Android APK را باز کن.
5. Artifact با نام AW-MUSIC-debug-apk را دانلود کن.

این نسخه پایه است و هنوز سرویس پخش پس‌زمینه، کنترل اعلان/صفحه قفل و پلی‌لیست‌های پایدار را ندارد. پشتیبانی فرمت‌ها به کدک دستگاه وابسته است.
